# Ada/SPARK Tools

This repository contains tools for the Ada/SPARK world. Initially we
have a single tool, but we do plan to add more:

* [GPR Checker](gpr_checker) a tool to enforce
  [SPARK Process](https://github.com/NVIDIA/spark-process)
  requirements on `.gpr` files.
